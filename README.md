# Renderprova2

# 🚗 Oficina Mecânica – Prova Final | LionsDev

Este repositório contém o código desenvolvido como parte da prova final do **Curso de Programação para Iniciantes** da startup **LionsDev**. O projeto simula um sistema de gerenciamento de uma **oficina mecânica**, com foco em operações de cadastro, atualização e consulta de serviços e clientes.

## 🛠 Tecnologias utilizadas

- **Node.js** + **Express** – Criação do servidor e das rotas HTTP  
- **MongoDB Atlas** – Armazenamento de dados na nuvem  
- **Postman** – Testes e monitoramento das requisições  
- **Render** – Deploy da API

## 📌 Funcionalidades principais

- Cadastro de clientes e veículos  
- Registro de ordens de serviço  
- Atualização e exclusão de dados  
- Listagem de ordens por cliente  
- Integração com banco de dados MongoDB
